## 모델 서빙(Model Serving)이란?

- 모델 서빙(Model Serving)은 학습되거나 준비된 AI 모델을 실제 애플리케이션이 호출할 수 있는 서버, 엔드포인트, 런타임에 올려 요청을 받고 추론 결과를 반환하게 하는 운영 과정입니다.
- 쉽게 말하자면, 모델 학습은 "요리법을 만드는 과정"이고, 모델 서빙은 단어 그 자체로 "그 요리를 손님 주문에 맞춰 계속 내보내는 식당 운영"에 가깝습니다. 
    - 모델 서빙은 모델 파일만 있다고 하여서 서비스가 되는 것이 아니므로, 해당 모델을 통해서 사용자의 요청을 받아야 하고, 입력 형식을 맞춰야 하고, 모델을 실행해야 하고, 결과를 응답해야 합니다. (+ 속도, 비용, 장애 대응)
